Chapter 1: Introduction to C

1.1 Definition — What is C?

C is a general-purpose, procedural, statically-typed, compiled programming language. "Procedural" means a C program is built from a sequence of instructions organized into functions; "statically-typed" means every variable's type is fixed at compile time; "compiled" means source code is translated into machine code by a compiler before the program runs, rather than being interpreted line-by-line.

1.2 History of C

  • 1969–1973: Dennis Ritchie developed C at Bell Labs, evolving it from an earlier language called B (itself derived from BCPL).
  • Purpose at creation: C was built to rewrite the UNIX operating system, which had originally been written in assembly language. This is why C gives programmers low-level control (like assembly) while still being readable.
  • 1978: Brian Kernighan and Dennis Ritchie published The C Programming Language.
  • 1989/1990: Standardized as ANSI C / C89 (and ISO C90 internationally).
  • Later standards: C99, C11, C17, C23 added modern extensions while maintaining backward compatibility.

📝 Note: C is often called the "mother language" of programming because compilers/interpreters for many later languages (C++, Java, Python's CPython, PHP) were written in C.

1.8 Structure of a C Program

Every C program follows a clean, predictable structure:

#include <stdio.h>

int main(void) {
    printf("Hello, World!\n");
    return 0;
}

Line-by-line explanation:

  1. #include <stdio.h> — A preprocessor directive including standard I/O function declarations.
  2. int main(void) — Execution entry point for the operating system.
  3. printf("Hello, World!\n"); — Prints the string to stdout with a newline.
  4. return 0; — Signals successful execution back to the host operating system.

Chapter 2: Tokens, Keywords, Identifiers, Constants & Variables

2.1 Tokens

A token is the smallest individual unit in C that the compiler recognizes. The C language contains 6 types of tokens: Keywords, Identifiers, Constants, String Literals, Operators, and Punctuators.

2.5 Variables

A variable is a named memory location that holds a value of a specific data type.

#include <stdio.h>

int main(void) {
    int age = 20;
    float height = 5.9;
    char grade = 'A';

    printf("Age: %d, Height: %.1f, Grade: %c\n", age, height, grade);
    return 0;
}

C provides fundamental data types: int, char, float, double, and void. Modifiers such as signed, unsigned, short, and long tailor memory ranges.

Chapter 4: Operators, Expressions & Type Conversion

C features rich arithmetic, relational, logical, bitwise, assignment, and ternary operators. Operator precedence dictates execution order when expressions omit parentheses.

#include <stdio.h>

int main(void) {
    int a = 17, b = 5;
    printf("a / b = %d (integer division)\n", a / b);
    printf("(float)a / b = %.2f (explicit cast)\n", (float)a / b);
    return 0;
}

Chapter 5: Input/Output & Escape Sequences

Input and output operations are handled via <stdio.h> functions such as printf(), scanf(), getchar(), putchar(), and fgets().

⚠️ Warning: Always check scanf() return values and prefer fgets() over the obsolete, unsafe gets().

Chapter 6: Decision Making

Conditional control flow executes branches based on truth values (non-zero is true; zero is false).

#include <stdio.h>

int main(void) {
    int score = 85;
    if (score >= 90) {
        printf("Grade A\n");
    } else if (score >= 80) {
        printf("Grade B\n");
    } else {
        printf("Grade C or lower\n");
    }
    return 0;
}

Chapter 7: Loops

C provides three looping structures: entry-controlled while and for loops, and exit-controlled do-while loops.

#include <stdio.h>

int main(void) {
    for (int i = 1; i <= 5; i++) {
        printf("%d ", i);
    }
    printf("\n");
    return 0;
}

Chapter 8: Jump Statements

Control flow jump statements include break (exits nearest loop/switch), continue (skips iteration), and goto (transfers execution to a named label within the function).

Chapter 9: Functions & Recursion

Functions promote modularity and code reuse. C passes arguments strictly by value.

#include <stdio.h>

int factorial(int n) {
    if (n <= 1) return 1;
    return n * factorial(n - 1);
}

int main(void) {
    printf("5! = %d\n", factorial(5));
    return 0;
}

Chapter 10: Arrays

Arrays store contiguous elements of identical data types in memory with 0-indexed bounds.

#include <stdio.h>

int main(void) {
    int numbers[5] = {10, 20, 30, 40, 50};
    for (int i = 0; i < 5; i++) {
        printf("numbers[%d] = %d\n", i, numbers[i]);
    }
    return 0;
}

Chapter 11: Strings & Character Arrays

In C, strings are null-terminated ('\0') character arrays. Always compare content with strcmp(), never ==.

Chapter 12: Pointers

Pointers hold memory addresses. Use & to fetch an address and * to dereference.

#include <stdio.h>

void swap(int *a, int *b) {
    int temp = *a;
    *a = *b;
    *b = temp;
}

int main(void) {
    int x = 5, y = 10;
    swap(&x, &y);
    printf("x = %d, y = %d\n", x, y);
    return 0;
}

Chapter 13: Dynamic Memory Allocation

Heap memory is allocated dynamically at runtime via malloc(), calloc(), and realloc(), and released via free().

Chapter 14: Structures, Unions, Enums & Bit Fields

struct groups heterogeneous fields in contiguous memory; union overlays fields sharing the same space; enum defines named integer constants.

Chapter 15: File Handling

Persistent storage is accessed via FILE* handles using modes ("r", "w", "a", "rb", "wb") with functions like fprintf(), fgets(), fread(), and fwrite().

Chapter 16: Command-Line Arguments

int main(int argc, char *argv[]) receives command-line arguments passed at startup.

Chapter 17: Preprocessor Directives & Macros

Pre-compilation text manipulation via #include, #define, and header guards (#ifndef / #define / #endif).

Chapter 18: Compilation, Linking & Execution

The build pipeline progresses through four distinct stages: Preprocessing → Compilation → Assembly → Linking.

Chapter 19: Error Handling & Undefined Behaviour

C relies on errno and return values. Undefined behavior (signed overflow, out-of-bounds access) should be detected with AddressSanitizer (-fsanitize=address).

Chapter 20: Best Practices & Interview Prep

Consolidated defensive programming rules: initialize variables, check allocation pointers, parenthesize macro parameters, and maintain consistent formatting.

Chapter 21: Introduction to Python

Python is a high-level, interpreted, dynamically-typed language prioritizing legibility and rapid development.

# Python Hello World
print("Hello, World!")

Chapter 22: Syntax, Variables & Core Collections

Python variables bind names to objects. Primitive numbers have arbitrary precision, and core collections include mutable list, immutable tuple, unique set, and key-value dict.

# List Comprehension Example
squares = [x**2 for x in range(1, 6)]
print(f"Squares: {squares}")

Chapter 23: Operators, I/O & Formatting

Python supports true division (/), floor division (//), exponentiation (**), f-string formatting, and safe input reading via input().

name = input("Enter name: ")
print(f"Hello, {name}!")
